# Paradise Nursery Shopping Application

## Project Name
Paradise Nursery Shopping Application

## Description

Paradise Nursery is an online plant shopping application developed
using React and Redux.

The application allows users to:

- Browse different categories of houseplants
- View plant names and prices
- Add plants to a shopping cart
- Increase or decrease quantities
- Remove plants from the cart
- View the total cart amount
- Continue shopping
- Use the checkout option

## Technologies Used

- React
- Vite
- Redux Toolkit
- React Redux
- React Router
- CSS
- JavaScript

## Plant Categories

1. Medicinal Plants
2. Flowering Plants
3. Indoor Plants

## Main Features

- Responsive navigation bar
- Dynamic cart count
- Add to Cart functionality
- Quantity management
- Delete cart items
- Total price calculation
- Checkout message
- Continue Shopping functionality
